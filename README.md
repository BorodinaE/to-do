# Задание

Доработать приложение ToDo лист:

- добавить текстовый инпут (со стейтом - useState, см лекцию)
- сделать добавление задачи из инпута в список задач (по кнопке, см add)
- сделать удаление (или - или):
  a) удаление конкретной задачи из списка - добавить кнопку в таблицу - предпочтительно
  б) удаление первой задачи из списка (добавить отдельную кнопку)
